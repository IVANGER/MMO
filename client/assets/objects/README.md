# 🖼 PNG-спрайты объектов (часть 9, День 8)

Сюда положить (имена должны совпадать):

- `tree.png` — дерево
- `rock.png` — камень

Рекомендуемый размер **32×48** (32×32 основание + 16px крона сверху),
режим RGBA с прозрачностью. Якорь при отрисовке — **bottom-center**
(низ картинки стоит на клетке), поэтому объекты корректно
сортируются по `y` вместе с персонажами.

Если файла нет — рендер рисует цветной прямоугольник с обводкой.
