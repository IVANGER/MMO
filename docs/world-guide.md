# Как делать карты

## Формат ASCII

```
####################
#..................#
#..TT..........TT..#
#........@.........#
#....~~~~....~~~~..#
####################

Легенда:
# = стена
. = трава
~ = вода
T = дерево
@ = спавн игрока
M = спавн моба
C = город
```

## Регионы

- Регион = сетка локаций (например, 3×3)
- Локации соединяются порталами по центру краёв
- Не все связи обязательны — можно делать «обходные пути»
- В памяти только текущая локация
